A wrist menu in VR and a full menu on PC: custom skies, shaders, a cosmetics shop with quests, arm items, T-shirts, ping pong, football, custom maps, a stream camera, an AI buddy and stream tools.
Everything visual is **local**, so it only changes what *you* see. Cosmetics are seen by other players who also have CooKir Menu.

## ✨ Highlights

| | |
|---|---|
| 🍪 **Quests & Shop** | 27 quests in 4 levels (easy → extreme), earn Cookies, buy cosmetics |
| 🎩 **Cosmetics** | 32 hats, blindfold tape, flag, **20 T-shirts** on the gorilla body |
| 🧸 **Arm items** | 33 items on your arm: squeezable plushies, bubble / confetti / snow guns, lightsaber, flashlight, photo phone and more. Grab with the other hand + grip, use with the trigger |
| 🏓 **Ping pong** | Real-size table, paddle in your hand, real spin and Magnus physics, a bot with 4 levels, real rules, ball machine, juggling, scoreboard and stats |
| ⚽ **Football** | Ball, goals with a real stretchy net, ball spin, score for the whole room |
| 🗺️ **Custom maps** | On MODDED (Utilla) in the forest: load `.glb / .gltf` (with animations), `.obj` or Unity AssetBundles. Example map **CooKir Park** built in |
| 🌈 **Shaders** | 40 looks (Golden Hour, Cyberpunk, VHS, Night Vision…) that never darken the picture |
| 🌌 **Skies** | Your own skyboxes, sky by time of day |
| 🎨 **Menu looks** | 30 themes (animated rainbow, flame, galaxy), backgrounds, frames, shapes |
| 🎥 **Camera** | Tripod, drone, spectate, orbit, MP4 recording, freecam, photos |
| 🏎️ **Speedometer** | Speed with the stopwatch, under name tags and on the monitor |
| ✋ **Effects** | 18 hand trails, confetti, flips others can see, full-body legs, trackers |
| 🤖 **AI buddy** | Voice AI (Claude / Grok / Groq): talks, searches the web, walks your gorilla in private rooms |
| 📺 **Stream tools** | OBS control, Twitch / YouTube / Tipply alerts, chat on screen, viewer commands |
| 🔄 **Updates** | A **DOWNLOAD** button appears in the menu when a new version is out |

## 📦 Installation

1. Install **[BepInEx 5](https://github.com/BepInEx/BepInEx/releases)** for Gorilla Tag.
2. Download **`CooKirMenu_3.dll`** from [Releases](https://github.com/MrCiastek-mods/Cookir-menu-GT/releases/latest).
3. Put it in `Gorilla Tag/BepInEx/plugins/`.
4. Start the game.

## 🎮 Controls

| | |
|---|---|
| **Open menu (VR)** | Hold **Y** (or B / X / A, set in SETUP). Click with the index finger of your other hand |
| **Open menu (PC)** | **Right Shift** |
| **Language** | SETUP → LANGUAGE / JEZYK (VR) or **EN > PL** in the PC title bar |
| **Photo** | **F2** |
| **Arm items** | Other hand on the item + **grip** to take it, **trigger** to use it |
| **Ping pong** | **Trigger** tosses the ball for the serve |

Settings are in `BepInEx/config/com.mrciastek.gt.cookirmenu.cfg`, but almost everything can be changed in the menu.

**Optional:** `ffmpeg.exe` in the game folder (camera recording) · MarioMonkeMadness with your own SM64 ROM (Mario) · your own Claude / Grok / Groq API key (AI; Groq has a free plan) · **Utilla** for modded rooms and custom maps.

## ⚠️ Notes

- Visual changes are local. Other players only see cosmetics, and only if they have CooKir Menu.
- The AI moves your gorilla **only in private rooms**, and you can take control back at any time.
- Mod detection in the menu is a hint, not proof. Please do not harass people based on it.
- Not affiliated with Another Axiom. Use mods responsibly and follow the game's rules.

🐛 Found a bug? Open an [issue](https://github.com/MrCiastek-mods/Cookir-menu-GT/issues) and attach `Gorilla Tag/BepInEx/LogOutput.log`.
